# spt-app 0.2.0

Released on 2026-10-21.

This release refreshes the simulation media from the current porous_media SPT
analysis and updates the application dependencies and development tools.

## Changes

- Rebuilt all 48 time-course images and 48 H.264 videos from the porous_media
  analysis at commit `fabd81b01908e1141bd31d7a519741511b4ecc46`. Videos contain
  200 frames spanning 24 simulated hours and use browser-compatible encoding.
- Updated simulation conditions, including the boundary flow values. All eight
  substrate flows are selectable for each of the six zonation patterns.
- Corrected the default selection to linear increase at substrate flow 3.
- Served bundled media through Streamlit, with muted autoplay, looping, seeking,
  accessible descriptions, and a responsive sidebar.
- Updated Streamlit to 1.66.0 and pandas to 3.0.6. Removed OpenCV and the system
  OpenGL dependency.
- Updated uv to 0.13.4 and added Ruff 0.17.1 and ty 0.0.90, with a regenerated
  lockfile and GitHub Actions checks.
- Added a documented media import workflow with artifact validation, provenance,
  SHA-256 hashes, and preparation of the complete cohort before replacement.
- Corrected the archival metadata to describe the SPT application and its MIT
  source code license.

## Validation

- All 11 tests pass, including selection coverage for all 48 simulations and
  integrity checks for every bundled asset.
- Ruff linting, Ruff formatting, and ty type checking pass.
- All 48 videos pass full decoding and checks for H.264, yuv420p, 200 frames,
  12 fps, and MP4 fast-start metadata.
- Chrome checks pass for desktop and mobile layouts, all six zonation patterns,
  bundled video hashes, autoplay, looping, and HTTP range seeking.
