# spt-app 0.3.0

Released on 2026-10-21.

This release adds the SPT convergence study alongside the existing zonation and
substrate-flow simulations.

## Changes

- Added a study selector and all seven convergence mesh resolutions, ordered by
  full-lobule cell count from 708 to 39,246 cells.
- Added seven matching time-course figures, mesh views, and H.264 videos, plus an
  overview of all meshes. Videos compare the shared interval from 0 to 36,590 s.
- Displayed actual history durations and completion status. The `09375` and
  `06250` histories stop at 77,687.6 and 36,590 s; native curves retain these
  endpoints.
- Added interactive native time courses, matched comparisons, spatial profiles,
  and differences from the finest available mesh. Linear and symlog views keep
  all seven meshes visible, including the coarsest mesh's large source values.
- Added TSV and NetCDF downloads. Necrosis remains a fraction in tables and mesh
  maps; quantitative plots display percentages. Undefined ratios remain missing.
- Normalized the mean-difference table's cell counts using active geometry
  metadata while preserving numerical differences and missing values.
- Added a documented convergence importer with active-generation checks,
  provenance, source and exported hashes, and cohort validation.

## Validation

- All 18 tests pass, including all 48 simulation selections, seven convergence
  selections, source completion, comparison intervals, numerical units, and
  bundled file integrity.
- Ruff linting, Ruff formatting, and ty type checking pass.
- All seven convergence videos pass full decoding and checks for H.264,

- Chrome checks cover desktop and mobile controls, all four result views,
